# 青空偏航

[青空偏航](../dist/matrix-anime.html) 使用五段日漫风格的视频，围绕白色建筑、蓝天与纸飞机展开。人物和镜头的变化来自视频，显影与固定点阵由网页实时处理。

| 章节 | 主要动作 |
|---|---|
| 追风起跑 | 侧面奔跑与正面推进 |
| 回眸擦镜 | 绕行近景与前景遮挡 |
| 螺旋下坠 | 纵深下落、旋转和追近 |
| 穿越方界 | 奔跑与跨跃几何门框 |
| 纸翼回航 | 纸飞机滑行、倾斜与下降 |

每个源片段长 5 秒、分辨率 720P。单幕 4.3 秒，点阵桥 0.85 秒，整轮 21.5 秒。桥接期间两段视频重叠播放，源视频播放倍率约为 0.963。

配置在 `examples/matrix-anime/`，素材见 [素材说明](../assets/matrix-anime/ASSETS.md)。运行步骤见 [复现说明](REPRODUCTION.md)。

部分片段有脸型和服装细节变化，个别结尾被前景遮挡或短暂出画。五源解码、循环接缝、确定性倒拖和移动布局由 `tests/browser_anime.py` 验证。
