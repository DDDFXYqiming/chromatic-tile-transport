# Matrix Motion 视觉使用指南

记录日期为 2026-09-10。本文件保存当前的视觉方向和下一阶段判断，供继续制作、审片和交接时使用。当前版本仍是阶段性实验。

## 当前画面做到哪一步

默认示例只有“浮光花园”这一组素材。四张输入图片组成五个图层实例，前后花枝共用一张图片。三个章节分别展示全景、人物近景和留白构图，人物、鱼、花枝与背景始终来自同一组输入。因此，当前三幕应称为同一场景的三个镜头，不能写成三组不同画面之间的转换。

程序已经实现局部网格形变，包括鱼身和尾部摆动、花枝弯曲、人物轻微呼吸和外侧头发运动。定机位测试能确认这些变化独立于镜头和整层位移。不过，用户的最新观感仍是素材没有充分动起来；这也是本阶段保留的问题。像素发生变化、网格没有翻折，只能说明实现正常，不能据此认定角色已经具有自然的表情、行为或表演。

接下来的两个重点分别是更有辨识度的主体动作，以及几组不同素材之间的连续切换。用户已明确把多组素材留到后续讨论，本次仅记录，不新增画组、不生成素材、不改动当前编排。

## 画面应该怎样使用这些效果

观看顺序应当让人先看清画里的主体，再感到主体和空间在动，最后通过点阵切换看到新的内容。转场需要有明确的出发画面和到达画面；当两边仍是同一人物、同一鱼和同一枝花时，它能展示技术，但提供的新信息有限。

完整原画承担主要观看时间。人物的脸、鱼的轮廓、花枝与留白之间的关系，应当在这一段稳定可读。局部动作可以持续发生，镜头移动应当帮助看清这些动作。若必须依靠大幅推拉才能感觉“动了”，就需要回到定机位检查主体本身。

色块、双色和线描用于短暂强调轮廓、材质或画面节奏。当前“原画、色块、双色、线描、点阵”的顺序是一条便于比较技术的基线，后续可以根据画组内容选择强调方式，不必让每个镜头以完全相同的强度展示所有效果。

点阵负责把观看带向下一组画面。进入、翻转、颜色接替和退出应当相互衔接，格点保留在屏幕固定位置。避免在入格后等所有格子站好再翻转，也避免转换完成后停着一整屏格子等待退出。这里的固定点阵属于效果 02；效果 01 的寻色格片迁移有独立规则。

| 内容 | 希望观察到的效果 | 出现问题时先看什么 |
|---|---|---|
| 人物 | 面部稳定、呼吸克制，头发与衣料有局部变化 | 关闭镜头和漂移后动作是否仍可辨认，五官有没有被牵拉 |
| 鱼 | 鱼身到尾端形成有方向的摆动 | 是否只是整条鱼平移或旋转，鳍和尾部有没有不自然的挤压 |
| 花枝 | 枝条与花朵的变化有轻重，和人物错开节拍 | 是否整枝像硬板一起摇摆，花瓣是否被拉得过薄 |
| 镜头 | 构图变化有目的，能把注意力带向主体 | 是否切掉脸、鱼尾或花朵，移动端是否把主体挤出画面 |
| 显影 | 短暂变化后仍能理解原画 | 是否长期只剩轮廓或双色，原画还没看清就开始下一段 |
| 点阵桥 | 前一画面顺畅交给后一画面 | 是否出现整屏闪白、停格、接缝跳变，转换后是否有新的内容 |

## 当前基线和调整顺序

以下参数来自当前配置和时间轴，只是本素材的工作起点，不是对所有素材都适用的最佳数值。

| 参数 | 当前值 | 用途 |
|---|---|---|
| `shotSeconds` | 5.2 秒 | 每幕总时长 |
| 原画观看段 | 3.04 秒 | 占主要观看时间 |
| `bridgeSeconds` | 1.20 秒 | 包含入格、翻转、换图和出格的整个点阵段 |
| 其余显影 | 合计 0.96 秒 | 快速恢复原画及色块、双色、线描强调 |
| `density` | 144 列 | 固定格点密度 |
| `zoom` | 1.65 | 镜头倍率控制，具体取景由相机关键帧决定 |
| `parallax` | 0.65 | 默认分层模式下的图层漂移与摆动比例 |
| `deformationStrength` | 1.0 | 当前素材的局部动作幅度，可调范围为 0–1.5 |
| `palette` | `ice` | 显影时使用的冰蓝纸白色盘，原画保留原色 |

先打开“原画”和“纯画面”，检查完整素材、前后关系与裁切。然后在一个合适取景打开“定机位看动作”，比较形变开启和关闭的差异。此时镜头与刚性图层姿态固定，底部时间轴仍控制局部动作。关掉形变后，时间变化应当保持同样的像素。

主体动作可以独立成立以后，再调整图层漂移和镜头。最后回到“导演编排”，决定显影和点阵桥的力度。一次只调整一个主要问题，并保留同一取景、同一时间段的前后对比。仅提高动作幅度，不能补出原素材中缺少的眼皮、口型或其他姿态。

导演台中的时间分配摘要来自 `MatrixTimeline.timing()`。修改镜头总时长时，点阵桥仍由独立的 `bridgeSeconds` 控制。历史五图示例的默认镜头时长与本示例不同，复制参数前先确认正在使用的配置文件。

## 后续多组素材怎样进入画面

未来的画组应当在主体关系、姿态、环境或构图上带来可辨认的变化，同时保留足够统一的色彩、线条和光照。判断一组新素材是否有价值，可以先跳过转场直接看两端原画，确认观众确实能看出内容发生了变化。

为相邻画组挑选一个可追踪的视觉联系，例如主体的大致位置、鱼的行进方向、花枝的斜线或局部色彩。也可以有意改变其中一项，但要让其他部分帮助观众理解去向。每一组都同时换主体位置、画风、亮度和运动方向，会使衔接难以判断。

当前代码用一个共享的 `composition` 加三组 `cameraKeys`，尚无逐画组素材集合。真正接入多组素材时，需要重新设计画组与镜头的关联、前后画组的同时合成、素材预加载和资源释放，并兼容现有单组配置。只增加章节名、替换缩略图或给相同素材增加相机关键帧，都不足以完成这一目标。具体结构和画组数量等用户开始下一阶段时再确定。

当时可按“原画静态对照、各组独立动作、相邻画组桥接、完整循环”的顺序验收。先让两组衔接成立，再扩大画组数量。复杂转头、眨眼或姿态转换需要合适的素材拆分或其他动画方案；本记录没有替后续任务选择视频模型，也没有授权新的生成调用。

## 技术验收与视觉验收分别记录

技术验收沿用倒拖可复现、暂停不连续重绘、格点固定、无空白帧、循环接缝连续、上下文恢复、手机布局、离线资源和效果 01 回归检查。Canvas 2D 兼容模式没有本轮局部网格形变，应当按其实际能力描述。

视觉验收还需要确认主体动作是否自然可辨、原画是否有足够观看时间、点阵后是否出现新的内容，以及一轮播放后是否仍感到重复。以用户实际观看反馈为准，保留未解决问题。自动测试通过和逐帧导出视频都不能替代这一步；导出视频也不能用作实时帧率成绩。
