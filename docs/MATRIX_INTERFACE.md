## 页面组成

页头统一为星形标记、系列名称、效果切换、影像档案、自动巡航、导演台和沉浸按钮。播放控制从画布移到页头，保留原暂停与播放行为。

画面左下方采用暖白中文衬线标题，逐幕读取已有的两行标题、英文名、章节序号和说明。原花园的三条说明改为与取景对应的简短文案。主按钮进入当前可见章节的下一幕；旁边保留双镜头慢速演示入口。

右上方状态卡显示真实播放状态、渲染后端和实际格点总数，不再只显示一个缩小的章节名称。右侧提供章节标记，底部保留滚动提示、章节状态、时间轴、影像缩略图和前后切换。时间轴的强调色与当前章节一致。

影像档案使用原生 dialog，可选择本组影像，也可在四个独立系列之间切换。分层版缩略图仍来自实际合成构图；视频版使用已保存的首帧封面。打开档案时暂停时间轴及视频播放，关闭后继续先前的巡航或保持先前的暂停。Escape 关闭对话框并返回打开按钮，选幕时同步底部缩略图、侧边标记、标题和当前章节。

默认展示完整界面，包括视频版。导演台的纯画面开关仍可隐藏画面文字、状态和装饰遮罩；沉浸继续隐藏页头与底部栏。小屏保留全部系列入口和章节选择，短竖屏收起次要说明，避免标题与状态卡互相遮挡。

## 实现范围与验证

源码集中在 src/matrix/index.template.html、style.css 和 main.js。没有修改 PixiJS 视频／网格实现、WebGL shader 或共享时间轴，也没有重新生成图片和视频。01 的源码及 dist/index.html 保持原内容。所有 Matrix 链接版和离线版由构建脚本生成。

tests/browser_matrix_interface.py 检查四系列可用、完整组件默认显示、档案选幕同步、模态暂停／续播、Escape 焦点返回、纯画面与沉浸，以及桌面、手机和横屏的遮挡与溢出。该检查已加入 scripts/check_matrix.py --browser。截图和结果位于 reports/interface/。

完整回归还覆盖已有分层动作、视频解码、倒拖像素一致、各处接缝、兼容路径与离线无外部请求；scripts/check.py --browser 验证寻色迁移保持正常。截图用于审查排版，不能替代真实播放或作为动画自然度评分。

本轮验证通过：新增界面 7 项，既有 Matrix 浏览器检查 79 项，寻色迁移浏览器检查 33 项，Python 测试 40 项及原效果数值测试 19 项。53 个原画、首帧、封面与视频源文件逐项核对哈希保持不变；回归生成的花园合成展示封面随新画布尺寸更新。四个系列的镜头与转场时长保持不变，八个链接／离线入口已重新构建。
