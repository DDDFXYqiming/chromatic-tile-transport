每个画组必须带来可辨认的新内容，同时延续整体美术语言。先比较两端完整原画，确认主体关系、构图或姿态确实改变，再设计连接它们的镜头和固定点阵桥。优先让两组完整跑通，随后再扩展。不要把增加章节名、缩略图或相机关键帧当作完成多画组切换。

给出兼容当前单组配置的实现方案，考虑画组与镜头的关联、桥接两端同时合成、图片预加载、资源释放、移动端取景和循环尾接首。使用 $pixijs 中相关方法，保留共享时间轴、倒拖可复现、减少动态和效果 01。

已有素材可直接使用。缺素材时先报告具体缺项，不自行调用图像或视频生成模型；生成工作需要我另行提出。不要把技术测试通过表述为最终视觉优化完成。提交和推送范围遵循我在这次任务中的明确要求。
