# 六套新效果浏览器验收

本次观察结论：底部导航已经连通全部八套效果；展厅与八个效果页均能显示，已操作的主要控件有可见反应。六套新效果整体的画面精细度明显低于寻色迁移和 Matrix，差距主要在舞台内容，页面外框和导航则较统一。

验收日期：2026-10-04，Asia/Shanghai。浏览器通过官方 Chrome 扩展连接，使用 `agent.browsers.get("chrome")`。入口为 `http://127.0.0.1:8765/`，访问时服务已可用。效果页当前桌面视口读数为 1707 × 735。以下依据本次实际截图、页面内容与操作结果。

## 1. 底部栏能否切换全部效果

能，但原来两套需要先切换底部栏的模式。

- 寻色迁移默认底部为五幕影像，点击左下角“八个体验 ↗”后，出现 01—08 八个带缩略图的入口，以及上一个／下一个体验。
- Matrix 默认底部也为五幕影像，同样有“八个体验 ↗”，展开后可进入全部八套。
- 六套新页面默认直接显示八项底部导航。
- 本次实际点击的路径为：寻色迁移 → Matrix → 画中门 → 时差场 → 液态画布 → 光学展柜 → 影子机关 → 折叠剧场 → 寻色迁移。全程使用底部的项目入口或“下一个体验”，最后验证了 08 → 01 的循环。
- 顶部仍呈现“01 寻色迁移”“02 MATRIX MOTION”和新体验的下拉入口。这种顶部样式容易让人误以为只有原来两套，但底部已能进入全部八套，新六套并非只能从展厅列表进入。

证据：[寻色迁移八项底栏](shots/04-transport-eight-menu.jpg)、[Matrix 八项底栏](shots/08-matrix-eight-menu.jpg)、[从第八套回到第一套并加载完成](shots/33-nav-wrap-loaded.jpg)。

## 2. 视觉精细度比较

寻色迁移可看到细节丰富的插画，以及大量格片在画面中迁移；Matrix 可看到角色战斗画面和线稿显影。它们的舞台内容、构图和场景变化比新六套丰富。新六套的字号、边框、控件区和底栏有一致性，但多数舞台更像原理演示。以下是这次桌面画面的主观比较，不将画风差异直接认定为功能故障。

| 新效果 | 与原来两套相比，实际看到的差距 | 截图 |
| --- | --- | --- |
