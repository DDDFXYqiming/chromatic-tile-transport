# Matrix Motion 视觉指南

完整画面承担主要观看时间，双色、线描和点阵用于短暂强调与衔接。调整参数前先以原画模式观看整轮，确认主体动作与构图清楚可辨。

## 判断动作

花园分层版的定机位开关固定镜头与图层整体姿态，便于观察鱼尾、花枝和人物局部形变。关闭形变后比较同一时间点，可以区分镜头位移与素材自身动作。

视频版可关闭画面自身运动，以首帧对照连续视频。快速动作中的手、脸和武器可能重绘，需结合完整播放判断。像素差异只能证明画面发生变化。

## 调整节奏

花园分层版每幕 5.2 秒，其中原画约 3.04 秒，点阵桥 1.2 秒。两个五镜头视频系列每幕 4.3 秒，点阵桥 0.85 秒。单幕时长与点阵桥分别控制，修改后查看导演台的时间摘要。

相邻镜头的桥接两端应恢复完整图像，末幕回到首幕也要连续。倒拖同一时间点应得到相同画面。实现见 [显影与时间轴](MATRIX_MOTION.md)。

## 选择素材

分层动画需要完整轮廓、真实透明通道和足够的裁切余量。镜头移动时要避免露出缺失区域。

视频系列以不同构图与动作形成章节变化。花园分层版的三个章节共用一组素材，属于三个取景。接入多组分层素材需要处理画组关联、桥接合成、预加载和资源释放。

## 观看与验证

先检查原画，再检查显影和点阵桥。桌面与手机取景不同，主体不应被标题或状态卡遮挡。完整构图适合横屏观看。

技术检查覆盖暂停、倒拖、循环接缝、兼容路径与离线资源。逐帧导出适合审片，设备性能仍需在实际播放中测量。
