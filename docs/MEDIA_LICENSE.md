# Media and licensing

The MIT license in the repository applies to the source code and scripts. It does not automatically grant rights to every image, video, cover or screenshot stored beside them.

## Included media

The `matrix-botanical`, `matrix-video`, `matrix-anime` and `matrix-battle` folders contain the visual material used by the current Matrix studies. Some files are generated with image or video tools, some are derived previews, and their records are kept beside the assets. A generated file can still have restrictions from its inputs, its service terms, or the way it was commissioned.

The older transport examples include user-supplied legacy artwork. It is kept as a historical demo input. The public code license does not turn that artwork into reusable commercial material.

## What is safe to reuse

The reusable part of the project is the code, the build logic and the documented technique, under the license in the repository. If you want to publish a derivative demo, replace the example media with images and video you have permission to use, then update the scene manifest and attribution notes.

Prompt files and generation records are provided for reproducibility of the project history. They do not grant ownership of the generated output or of any reference image.

When redistributing a page, keep the relevant attribution and provenance information with the media. Do not present the example imagery as official material from a game, studio or model provider.

## Public repository boundary

Making the repository public exposes the files that are committed to GitHub. It does not change the underlying rights of the media. If a future release needs a fully redistributable media pack, put that pack in a separate, explicitly licensed asset set and keep the historical inputs out of it.
