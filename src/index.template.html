每块格片如何找到目的地？ ＋

先对实际可见区域逐格采样，把平均颜色转换到 OKLab；再在颜色、位置和局部明暗变化组成的空间里做等量分组，同组按排名配对，并通过局部交换降低色差和相邻流向的不协调。所有目标格子只能占用一次。迁移时携带原图纹理，沿由匹配结果计算的曲线前进，抵达后才逐渐换成目标纹理。

这是近似的一对一颜色搬运，不保证全局最优，也不认识人物、头发或天空。两张图的色彩比例不同时，无法让所有格片始终不变色，因此在落位阶段修正剩余色差。正常情况下匹配在 Web Worker 中完成；WebGL 2 负责显示。不支持 WebGL 2 时，Canvas 2D 仍使用同一套颜色映射。

V3.1 连续时间轴：格片边分离边启程、边落位边填缝；保留颜色相关的先后次序，不再等所有格片完成一个阶段才进入下个阶段。
