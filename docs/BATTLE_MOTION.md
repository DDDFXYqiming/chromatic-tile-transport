# 绯刃交锋

[绯刃交锋](../dist/matrix-battle.html) 展示红衣剑士与深蓝对手的五段战斗。青色与紫色刀光贯穿各幕，场景使用明亮的混凝土竞技场。

| 章节 | 主要动作 |
|---|---|
| 刃前对峙 | 对峙、接近与首次交锋 |
| 疾行突进 | 冲刺、低姿态闪避与转身 |
| 双刃交锋 | 剑击交换与环绕镜头 |
| 腾空避斩 | 腾空、旋身与落地 |
| 青刃决意 | 跨步下劈、冲击波与收势 |

每个源片段长 5 秒、分辨率 720P。单幕 4.3 秒，点阵桥 0.85 秒，整轮 21.5 秒。源片段在桥接处重叠播放，播放倍率约为 0.963。

配置在 `examples/matrix-battle/`，素材见 [素材说明](../assets/matrix-battle/ASSETS.md)。构建方式见 [复现说明](REPRODUCTION.md)。

快速动作中仍有脸型、护手和服装细节变化。近身交错会造成轮廓重叠，部分低机位镜头裁去头部。完整构图适合横屏观看。

`tests/browser_anime.py --profile battle` 检查解码、接缝、倒拖、章节导航及离线资源。
